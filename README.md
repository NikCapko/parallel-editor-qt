# Parallel Translation Editor

Десктопный редактор для работы с книгами в формате параллельного перевода: слева оригинал (`.en.md`), справа перевод (`.ru.md`). Синхронизация между панелями — **по клику на абзац**, а не по прокрутке: клик по строке подсвечивает её и выравнивает парный абзац на другой стороне по вертикали.

## Возможности

### Редактирование
- **Две панели** с номерами строк и подсветкой активной строки (жёлтый фон в светлой теме, тёмно-серый в тёмной).
- **Подсветка Markdown-синтаксиса**: заголовки `# … ######` (с увеличением размера по уровню), `**bold**`, `*italic*`, `***bold italic***`, `` `code` ``, `[ссылки](url)`.
- **Оглавление (Outline)** слева и справа — автоматически собирает все заголовки `#` и `**bold**`-строки; клик по пункту переходит к заголовку и синхронизирует панели.
- **Форматирование по горячим клавишам**: жирный, курсив, bold-italic, заголовки H1–H5.
- **Нормализация текста** (`Ctrl+Alt+L`) — применение правил коррекции ко всему тексту обеих панелей (через `text_corrector.normalize_text`).

### Синхронизация
- Клик по строке в любой панели → выделяется **только эта строка**, а парный абзац (с тем же индексом) на другой стороне выравнивается по вертикали.
- Синхронизация **не привязана к скроллу** — это осознанный выбор: абзацы в оригинале и переводе часто имеют разную высоту, поэтому привязка «строка к строке» работает точнее, чем пропорциональный скролл.

### Поиск и замена (`Ctrl+F` / `Ctrl+R`)
- Поддержка **обычных строк** и **регулярных выражений** (Python `re`, доступны `\1`, `\g<name>`).
- Опции: **учёт регистра**, **regex**, **выделить все совпадения** (жёлтым, текущее — оранжевым).
- Область поиска: активная панель / оригинал / перевод / обе панели.
- **История запросов** (до 20 записей) сохраняется между запусками через `QSettings`; очищается через контекстное меню поля ввода.

### Метаданные книги (`Ctrl+M`)
Сохраняются в `.bnf` рядом с парой `.en.md` / `.ru.md`. Схема:
- `title`, `orig_name`, `author`, `lang` (фиксированно `en-ru`), `tags`, `favorite`, `description`.
- **Теги в виде «чипов»** (кликабельные «пилюли» в `FlowLayout`).
- **История тегов** в `~/.bnf_tag_history.json` — все когда-либо использованные теги, отсортированные по алфавиту.
- Автозаполнение `title` и `author` из имени файла вида `«Название [Автор]»`.

### Перевод с помощью браузера
- **Файл → Открыть в Google Chrome…** / **…в Yandex Browser…** — сохраняет текущий оригинал во временный `.en.md` и открывает его в нужном браузере (ищет `google-chrome-stable`, `chromium`, `yandex-browser-stable` и т. п. через `shutil.which`).

### Экспорт (`PDF` / `EPUB`)
Через модуль `export_parallel.export_file`:
- Два режима вёрстки:
  - **Таблица** — две колонки (оригинал | перевод).
  - **Построчно** — оригинал, затем перевод блоками (interlinear).
- Опция «Открыть после сохранения» (через `xdg-open` / `QDesktopServices`).

### Темы
- **Светлая** и **тёмная** темы (Fusion + кастомная палитра).
- Выбор сохраняется в `QSettings` (`ui/theme`) и применяется при следующем запуске.
- Переключается через меню **Вид → Тема**.

## Структура файлов

Для одной книги используются три файла с общим базовым именем:
```
book.en.md   — оригинал
book.ru.md   — перевод
book.bnf     — метаданные (JSON)
```

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate.fish
pip install -r requirements.txt
python editor.py [путь_к_файлу.en.md]
```

Зависимости: `PySide6`, а также опциональные модули `export_parallel` и `text_corrector` (для экспорта и нормализации).

## Горячие клавиши

### Основные
| Действие                  | Клавиши             |
|---------------------------|---------------------|
| Открыть пару              | `Ctrl+O`            |
| Сохранить                 | `Ctrl+S`            |
| Сохранить как…            | `Ctrl+Shift+S`      |
| Метаданные книги          | `Ctrl+M`            |
| Найти                     | `Ctrl+F`            |
| Заменить                  | `Ctrl+R`            |
| Исправить текст (обе панели) | `Ctrl+Alt+L`     |
| Выход                     | `Ctrl+Q`            |

### Форматирование (в редакторе)
| Действие         | Клавиши           |
|------------------|-------------------|
| Жирный           | `Ctrl+B`          |
| Курсив           | `Ctrl+I`          |
| Жирный курсив    | `Ctrl+Shift+B`    |
| Заголовок H1…H5  | `Ctrl+1` … `Ctrl+5` |

## Использование

1. **Файл → Открыть пару…** — выберите `.en.md` или `.ru.md`, программа автоматически найдёт соседний файл с тем же базовым именем.
2. Редактируйте текст. Клик по строке подсвечивает её и выравнивает парный абзац на другой панели.
3. Используйте **оглавление** слева/справа для быстрой навигации по заголовкам.
4. `Ctrl+F` / `Ctrl+R` — поиск и замена с поддержкой regex и истории.
5. `Ctrl+M` — заполнить метаданные книги (название, автор, теги, описание).
6. **Перевод → Открыть в Google Chrome…** — открыть оригинал в браузере со встроенным переводчиком.
7. **Файл → Экспорт в PDF/EPUB…** — выбрать режим вёрстки (таблица / построчно) и сохранить.
8. **Вид → Тема** — переключение между светлой и тёмной темой.
